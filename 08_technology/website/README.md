## Deployment safeguards
This website is a static concept demonstration, not an enrollment solution. It must not imply fees, dates or venue have been confirmed. Before public deployment, test mobile responsiveness, meaningful heading order, keyboard navigation, accessibility contrast and optional English/Telugu copy.

Do not integrate payment, analytics, tracking cookies, unreviewed waitlist service, child media or direct-to-child AI interactions without a privacy/safeguarding review. Do not put real children, guardian records or API keys into the source code.

**Release flow:** staging preview → founder message approval → safeguarding/privacy sign-off → deployment with HTTPS → functional mobile review → monitor questions/complaints and factual accuracy. Log version, reviewer and date.
